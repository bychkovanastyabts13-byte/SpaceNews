# Космические новости (вариант №24)

Мобильное приложение для Android (Kotlin + Jetpack Compose): новостной агрегатор космических исследований и запусков.

## Экраны
1. **Лента** — актуальные новости космонавтики (16 материалов), фильтр по категориям, главная карточка, pull-to-refresh (потяните ленту вниз и отпустите — лента обновится).
2. **Чтение публикации** — большая иллюстрация, заголовок, полный текст, кнопки «назад» и «закладка».
3. **Закладки «Читать позже»** — сохранённые новости хранятся в памяти телефона и доступны без интернета.

## Структура проекта
```
app/src/main/java/com/spacenews/app/
├── MainActivity.kt
├── data/         — модель новости, список новостей (ArticlesData.kt), хранилище закладок
├── navigation/   — маршруты
└── ui/
    ├── theme/        — цвета
    ├── components/   — карточки, иконки, иллюстрации, pull-to-refresh, нижняя панель
    └── screens/      — экраны
```
Интернет приложению не нужен: новости и иллюстрации встроены, закладки хранятся локально.

## Как получить APK через GitHub
1. Создай репозиторий на github.com и загрузи в него всё содержимое папки (включая скрытую `.github`).
2. Открой вкладку **Actions** — сборка запустится сама (или **Build APK → Run workflow**).
3. Через 5–10 минут открой завершённый запуск и внизу, в **Artifacts**, скачай **SpaceNews-APK**.
4. Распакуй архив — внутри `app-debug.apk`. Скопируй его на телефон и установи (Android 8.0+).
